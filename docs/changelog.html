Graft graft's own code, commands, settings and packaging

  • FeatureCLI & configurationNew "graft parts" command lists the parts a very large repository was split into when it was built.
  • FeatureCLI & configurationThe parts of a repository built in parts are now linked to each other. Caller lookups, "who calls X" questions, search ranking and the repository overview follow calls from one part into another.
  • FeatureSavings & pricingPlain-text files (.txt) can now be indexed. This is off by default. Each file is cut into chunks at its headings or paragraph breaks, and each chunk keeps its own line range, so a search points at the right part of a large log, spec or data dump instead of the whole file. Files up to 50 MB are read, binary files saved with a text name are skipped, and text chunks are never sent for AI summaries, so they cost no AI tokens.
  • FeatureCLI & configurationNew settings choose which folders plain-text files are taken from and add other extensions to index the same way (.log, .out, ...). Extensions graft already parses as code or data are refused. The settings work as build options and as repository settings, apply to multi-repository workspaces and split builds too, and are described in the help and the README.
